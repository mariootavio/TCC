# Step 5: Checkpoint — Aprovar Especificação Visual

Apresente ao usuário o conteúdo completo de
`squads/landing-page-amparo/output/especificacao-visual.md`: o design system
(cores, tipografia, espaçamento, grid) e a especificação visual de cada
seção. Destaque explicitamente se a paleta está marcada como "PENDENTE" por
falta de identidade visual publicada por `marca-design-amparo`.

## Instructions

1. Resumir o design system (cores principais, tipografia) e perguntar se o
   usuário aprova, ou se quer ajustar algo (cor, espaçamento, direção de
   imagery de alguma seção).
2. Se a paleta estiver marcada como pendência, perguntar explicitamente: o
   usuário quer (a) seguir com a paleta provisória por agora, sabendo que
   precisará trocar quando a marca publicar, ou (b) pausar este pipeline e
   rodar `marca-design-amparo` primeiro.
3. Se o usuário pedir mudanças, voltar ao Step 4 (Vitória Visual) com o
   feedback específico.
4. Se aprovado, seguir para o Step 6 (Fábio Front-end) — a partir daqui, o
   código real começa a ser escrito no diretório externo confirmado no Step 1.

Nunca avance para a implementação sem aprovação explícita do design visual.
