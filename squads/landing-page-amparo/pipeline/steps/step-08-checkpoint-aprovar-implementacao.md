# Step 8: Checkpoint — Aprovar Implementação (Código + Animações)

Apresente ao usuário um resumo de `implementacao-frontend.md` (Fábio) e
`animacoes.md` (Mariana): o caminho absoluto do projeto, os comandos para
rodar localmente, a estrutura de componentes, as animações aplicadas por
seção, e a confirmação de que a Saída Rápida está livre de animação.

## Instructions

1. Sugerir explicitamente que o usuário rode o projeto localmente (comandos
   já documentados em `implementacao-frontend.md`) e veja o resultado no
   navegador antes de aprovar — esta squad não substitui a verificação visual
   humana.
2. Perguntar se a implementação e as animações estão aprovadas, ou se algo
   precisa de ajuste (seção específica, comportamento de uma animação,
   problema visual encontrado ao testar).
3. Se o usuário pedir mudanças, voltar ao Step 6 (Fábio Front-end) com o
   feedback específico — Fábio coordena com Mariana se a mudança afetar
   animação também.
4. Se aprovado, seguir para o Step 9 (Rafael Rigor) para a revisão final de
   qualidade.

Nunca avance para a revisão final sem que o usuário tenha tido a chance de
ver o site rodando de verdade.
