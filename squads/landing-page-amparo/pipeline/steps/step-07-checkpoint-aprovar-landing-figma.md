# Step 7: Checkpoint — Aprovar Landing Page no Figma

Apresente ao usuário um resumo de `implementacao-figma.md` (Diego): o
nome/link do arquivo Figma, as seções construídas, as imagens geradas e o
motion aplicado.

## Instructions

1. Sugerir explicitamente que o usuário abra o arquivo Figma e veja o
   resultado navegando pelo protótipo antes de aprovar — esta squad não
   substitui a verificação visual humana direto no Figma.
2. Perguntar se a landing page (copy, visual, imagens e motion) está
   aprovada, ou se algo precisa de ajuste (seção específica, imagem a
   trocar, comportamento de um motion, problema visual encontrado).
3. Se o usuário pedir mudanças, voltar ao Step 6 (Diego Assets) com o
   feedback específico.
4. Se aprovado, seguir para o Step 8 (Rafael Rigor) para a revisão final
   de qualidade.

Nunca avance para a revisão final sem que o usuário tenha tido a chance de
ver a landing page de verdade no Figma.
