# Step 6: Checkpoint — Aprovar Fluxos de UX

Apresente os fluxos de UX desenhados por Joana Jornada
(`squads/fluxos-uxui-amparo/output/fluxos-ux.md`) ao usuário para revisão
antes de avançar para a criação de telas de alta fidelidade.

Pergunte explicitamente:

- Cada fluxo crítico (acionamento de emergência, registro de
  denúncia/evidência, modo disfarçado, rede de apoio) está completo, com
  caminho feliz e caminho de erro mapeados?
- A ancoragem de cada fluxo ao backlog do brainstorm (RF-CORE ou ideia
  priorizada) está correta e completa?
- Os pontos de verificação de segurança/discrição (saída rápida,
  notificações neutras) estão presentes onde fazem sentido dentro de cada
  fluxo?
- Há algum fluxo crítico da missão do Amparo que está faltando nesta
  rodada?

Se o usuário aprovar, o pipeline segue para o Step 7 (criação de telas de
alta fidelidade por Telma Tela). Se o usuário pedir ajustes, volte ao Step 5
(Joana Jornada) para revisar os fluxos antes de seguir.

Nunca avance para a criação de telas sem confirmação explícita do usuário
sobre os fluxos de UX — toda a produção visual de Telma e a prototipagem de
Pietro dependem da qualidade e completude destes fluxos.
