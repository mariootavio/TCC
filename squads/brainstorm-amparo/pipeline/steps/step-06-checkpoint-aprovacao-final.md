# Step 6: Checkpoint — Aprovação Final

Apresente ao usuário o veredito de revisão de Carla Critério
(`squads/brainstorm-amparo/output/revisao-ideias.md`), juntamente com o
backlog de ideias de Bruno Brainstorm
(`squads/brainstorm-amparo/output/ideias-brainstorm.md`), para aprovação final
deste ciclo de brainstorm.

Pergunte explicitamente:

- Você concorda com o veredito de Carla Critério (APROVAR / REJEITAR /
  APROVAÇÃO CONDICIONAL)?
- O ranking RICE das ideias aprovadas reflete a prioridade que você gostaria
  de dar a elas no roadmap do Amparo?
- Há alguma ideia do backlog que você quer ajustar manualmente, promover ou
  remover antes de considerar este ciclo de brainstorm concluído?

Se o usuário aprovar o backlog final priorizado, este ciclo de brainstorm é
encerrado — o backlog e o veredito ficam disponíveis em
`squads/brainstorm-amparo/output/` para consulta em futuras rodadas ou para
alimentar outras squads do projeto (ex.: squad de design/UX, squad de
desenvolvimento).

Se o usuário não aprovar, retorne ao Step 4 (Bruno Brainstorm) para gerar ou
ajustar ideias, seguindo o mesmo fluxo de correção usado em caso de rejeição
por Carla Critério.

Este checkpoint é obrigatório antes de finalizar o ciclo — nenhuma rodada de
brainstorm deve ser considerada concluída sem confirmação explícita do usuário
sobre o backlog final e seu ranking de prioridade.
