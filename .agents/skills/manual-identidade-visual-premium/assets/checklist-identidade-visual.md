# Checklist de Identidade Visual — Página única

Este é o **checklist consolidado de uma página** que vai *dentro* do manual final entregue ao cliente, geralmente na penúltima ou última página. Diferente dos 7 checklists detalhados em `references/checklist-auditoria.md` (que são exaustivos por perfil), este aqui é a **versão compacta operacional** — feita para ser consultada em 30 segundos antes de aprovar uma peça.

Se o cliente imprimir uma página do manual e pendurar na parede do escritório, é esta.

---

## CHECKLIST DE CONSISTÊNCIA — [Nome da Marca]

**Use antes de aprovar qualquer peça. Todos os itens aplicáveis precisam estar marcados.**

### LOGOTIPO
- [ ] É uma das versões oficiais (principal, horizontal, vertical, monograma ou selo)
- [ ] Área de proteção (2X) respeitada — nada toca o logo
- [ ] Tamanho acima do mínimo ([X]mm impresso / [X]px digital)
- [ ] Proporções originais preservadas (não esticado, não comprimido)
- [ ] Cor é uma das aplicações oficiais
- [ ] Sem contornos, sombras ou efeitos aplicados
- [ ] Contraste suficiente com o fundo

### CORES
- [ ] Todas as cores estão na paleta oficial (principal ou apoio)
- [ ] Proporção 60/30/10 respeitada
- [ ] Cor primária não está como fundo de bloco de texto corrido
- [ ] Em impresso: arquivo em CMYK
- [ ] Em digital: arquivo em RGB
- [ ] Gradientes (se usados) são oficiais — não inventados

### TIPOGRAFIA
- [ ] Fontes oficiais (não substituídas por similares)
- [ ] Hierarquia respeitada (H1 maior que H2 maior que H3)
- [ ] Máximo 2 famílias tipográficas na peça
- [ ] Alinhamento padrão (corrido à esquerda, destaque centralizado)
- [ ] Letter-spacing correto em caixa alta (aberto) e baixa (normal)

### ELEMENTOS VISUAIS
- [ ] Ícones do sistema oficial — não pegos do Google
- [ ] Todos os ícones com mesmo estilo (linear OU preenchido, não misturado)
- [ ] Padrões/grafismos usados pertencem à marca
- [ ] Foto segue a direção fotográfica do manual (mood, tratamento)

### COMPOSIÇÃO
- [ ] Margens respeitam o mínimo definido
- [ ] Respiro suficiente entre elementos
- [ ] Hierarquia visual clara — o olho sabe onde ir primeiro
- [ ] Um foco por peça (sem dois elementos competindo)
- [ ] Alinhamentos rigorosos (tudo no grid)

### VOZ E COPY
- [ ] Texto soa como a marca falaria
- [ ] Palavras usadas estão na lista "diz"
- [ ] Nenhuma palavra da lista "não diz"
- [ ] CTA (se houver) é claro e direto

### TÉCNICA
- [ ] Resolução adequada (300dpi impresso pequeno, 150dpi banner, 72dpi tela)
- [ ] Sangria de 3mm em impressos
- [ ] Fontes embedded ou convertidas em curvas
- [ ] Arquivo nomeado no padrão da marca
- [ ] Versão editável salva + versão final exportada

### CANAL ESPECÍFICO

**Se for rede social:**
- [ ] Legível no preview sem zoom
- [ ] Texto dentro da zona segura (Stories/Reels)
- [ ] Combina com os últimos 9 posts (mosaico do feed)

**Se for impresso:**
- [ ] CMYK + 300dpi + sangria 3mm
- [ ] Cor testada em amostra física

**Se for digital/web:**
- [ ] Contraste WCAG AA (4.5:1 para texto)
- [ ] Otimizado em peso (WebP ou JPG comprimido)
- [ ] Testado em mobile

## Como usar este checklist no manual

**Versão dentro do PDF do manual:**
Diagrame esta página com generosidade. Use a tipografia da marca. Cada bloco (LOGOTIPO, CORES, etc.) com pequeno espaço entre eles. Checkboxes desenhados como quadradinhos vazios (□). Pode incluir o logo discreto no rodapé. Permite que o cliente imprima essa página em A4 e use diretamente.

**Versão para grandes equipes:**
Sugira ao cliente transformar este checklist em **formulário** (Google Form, Typeform, Notion) que o designer preenche antes de submeter peças. Cria registro auditável e cultura de responsabilidade pela marca.

**Versão para fornecedores externos:**
Adapte enviando só os itens técnicos (cores em CMYK, fontes, resolução, sangria, materiais). Esconde o que não interessa a eles (voz, copy, hierarquia editorial).
