# Briefing — Template de coleta de informações da marca

Este é o questionário que você (Claude) usa internamente para mapear o que precisa saber antes de produzir o manual. Também pode ser entregue ao usuário/cliente como **documento de coleta** quando ele estiver começando do zero.

## Como você (Claude) usa este briefing

**Caso 1 — Cliente respondeu o briefing inteiro:**
Vá direto à Etapa 1 do processo (Diagnóstico). Você tem material para tudo.

**Caso 2 — Cliente enviou material visual mas não respondeu briefing:**
Examine os arquivos primeiro. Extraia o máximo de respostas dos próprios arquivos (segmento, posicionamento, paleta, tipografia, personalidade visual). Identifique os **3 maiores gaps** entre o que você consegue inferir e o que precisa para um manual sólido. Pergunte apenas esses 3.

**Caso 3 — Cliente disse apenas "faz o manual da minha marca X":**
Use as perguntas das seções 1, 2 e 6 como base — esses são os bloqueantes absolutos. Pergunte essas 3 áreas agrupadas, em no máximo 3 perguntas curtas, e prossiga com suposições explícitas para o resto.

**Caso 4 — Briefing fornecido como conversa/transcrição (não estruturado):**
Releia a conversa procurando respostas para cada seção deste briefing. Onde a conversa for ambígua, faça a interpretação mais razoável e sinalize no diagnóstico ("Assumi X com base em Y — me avise se for diferente").

## Como entregar este briefing ao cliente

Se o cliente pedir o briefing para preencher antes de você produzir o manual, entregue-o:

- Em formato Markdown estruturado (pode ser copiado para Google Docs)
- Ou em formato `.docx` editável (usar skill `docx`)
- Ou como formulário em Notion/Typeform (orientar o cliente a montar)

Não entregue o briefing inteiro sem contexto — apresente em blocos progressivos: "Aqui está o briefing. Comece pela Seção 1 e 2 e me devolva. Depois te envio as seções seguintes."
